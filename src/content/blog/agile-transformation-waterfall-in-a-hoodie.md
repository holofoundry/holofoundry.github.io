Stand-ups every morning. Boards with columns. A retrospective that somehow never changes anything. Congratulations: you've installed the costume.

## Ceremonies without culture

Agile without the ability to change course mid-flight is waterfall with better fonts. If decisions still require a quarterly steering group and a change request form, the hoodie isn't helping.

## The retrospective giveaway

If retros produce actions nobody owns, or the same actions every fortnight, you're performing reflection. You're not doing it.

## What to do instead

Fewer ceremonies. Clearer ownership. Shorter feedback loops with real users. The manifesto was never about Jira workflows.
